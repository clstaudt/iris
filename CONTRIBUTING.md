# Contributing to Iris

Contributions are welcome. Before a pull request from you can be merged, you sign the [Contributor License Agreement](CLA.md) once: on your first pull request, a bot asks you to, and you sign by commenting the sentence it gives. You keep the copyright in your contributions; the agreement lets Iris be distributed under the GNU Affero General Public License and, should that be needed, under other terms.

How to set up Iris for development and run its tests: [docs/development.md](docs/development.md). How pull requests are made and merged: [AGENTS.md](AGENTS.md).
